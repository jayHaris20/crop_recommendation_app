# 🌾 ML-Based Crop Recommendation System

An end-to-end Machine Learning web application designed to recommend optimal crops based on soil nutrients and climatic parameters.

🚀 **Live Demo:** [Click Here to Open App](https://YOUR-STREAMLIT-APP-URL.streamlit.app)

---

## 📌 Features
- **High Accuracy ML Model:** Random Forest Classifier trained with **99.55% accuracy**.
- **Interactive UI:** User-friendly interface built using Streamlit.
- **Real-Time Predictions:** Instant crop suggestions based on 7 input parameters ($N, P, K$, Temperature, Humidity, pH, Rainfall).

---

## 🛠️ Tech Stack
- **Language:** Python
- **ML Framework:** Scikit-Learn (Random Forest)
- **Data Processing:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Deployment:** Streamlit Community Cloud
